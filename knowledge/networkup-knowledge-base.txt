9. CONDITIONAL CAMPAIGN LOGIC
==================================================

NetworkUp supports conditional logic.

Conditions include:
- If Connected
- If Connection Accepted
- If Replied
- If No Reply
- If Message Seen
- If Profile Viewed

Example:

Send Connection Request
→ Wait
→ Check whether connection was accepted
→ If YES: continue to messaging
→ If NO: follow the configured alternative path

Another example:

Send Message
→ Wait 2 Days
→ Check whether the prospect replied
→ If YES: stop or follow the configured response workflow
→ If NO: send a follow-up

Campaigns can therefore branch according to prospect behavior rather than following only one fixed sequence.
